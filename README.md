Token Radar ranks pre-token protocols by an implied token value from a fitted comps curve: log market cap on log TVL over the traded tokens, one row per ticker, with a shrunk category effect, small capped growth and seasoning tilts, a fitted chain-count term, and token odds from the peers' record by age bucket — implied value is value-if-launches times odds. Every term is tested held-out twice (leave-one-out and older tokens pricing newer ones) against a flat-multiple baseline, and the board prints the ablation table, the range honesty, and a bootstrap rank range per row. All 758 snapshot protocols are accounted for (ranked, already trading, or set aside by rule), and every row carries a costed farm verdict — FARM, MARGINAL-THIN or SKIP — from a slice of the implied value net of per-chain gas and the 4% T-bill forgone, with a step-by-step plan that states its cost and time. The dashboard is a static dark-themed page that recomputes every row in the browser: a sortable, filterable board, a full-page detail view per protocol with the value decomposition and nearest traded peers, a live-token view, and a method tab with the scatter plot and the out-of-sample results. Round 4 added a second evidence panel (the token-odds Brier ladder and the peers'-record bar chart), "Best farms now" cards, a break-even odds line, and a peers table that hides outliers more than 10× off the curve — the model itself was unchanged from round 3. Round 5 adopts the chain-count term into the value model (radar-4): its slope is fitted on the comps' residuals inside each fold, and it passed both held-out tests in round 4's ablation; log-age was tested the same way and is still not adopted. The dashboard's evidence panel shows the term live, and every row carries its own chain-count factor so the in-browser recompute still lands on board.json. Round 6 widens the watchlist: the board now ranks 60 watchlist protocols instead of 40 — every rankable protocol at or above the $50M floor, including the twenty the kit's list leaves out only because DefiLlama ties them to a parent protocol — with a floor ledger accounting for all 132 no-token protocols at or above $50M (60 ranked, 72 set aside by rule) and the full 144-row set-aside list on the Method tab. The model and every implied value are unchanged from round 5: board.json is byte-identical. It runs fully offline with zero network requests.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input <snapshot.json>
```

Then serve `out/` and open `dashboard/index.html`. Node.js 22 or later is all it needs — no build step, no dependencies. The four screenshots in `screenshots/` are renders of the dashboard itself: the board, a protocol's detail view, a FARM-only filtered view, and the method tab.
